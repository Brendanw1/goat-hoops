# Sources

Generated by `pipeline/sources.py` from the last bake. Every number on the site traces to a feed call, a method, a code path, a pre-registered gate (`pipeline/results/RESULTS-HOOPS.md`) and a published reference.

## Feeds

- **ESPN scoreboard** (`espn_scoreboard`): `GET https://site.api.espn.com/apis/site/v2/sports/basketball/nba/scoreboard?dates=YYYYMMDD`. game ids, dates, status, final scores. Terms: public API, no key. Stored: hoops_mart data/mart/games.parquet.
- **ESPN team schedule** (`espn_schedule`): `GET https://site.api.espn.com/apis/site/v2/sports/basketball/nba/teams/{team_id}/schedule?season=YYYY`. the authoritative game list (the scoreboard misses some games on their date). Terms: public API, no key. Stored: hoops_mart data/mart/games.parquet.
- **ESPN game summary: box score** (`espn_box`): `GET https://site.api.espn.com/apis/site/v2/sports/basketball/nba/summary?event={game_id}`. player and team box scores, starters, minutes. Terms: public API, no key. Stored: hoops_mart data/mart/player_game.parquet, team_game.parquet.
- **ESPN game summary: play-by-play** (`espn_pbp`): `GET https://site.api.espn.com/apis/site/v2/sports/basketball/nba/summary?event={game_id}`. every play with clock, score, type text and participants; shots carry x/y. Terms: public API, no key. Stored: hoops_mart data/mart/pbp.parquet, shots.parquet. Caveat: `seq` is not chronological (late scorer corrections get a higher seq); every reader orders by period, game clock, then running score (creation.ordered). The mart's clock_sec is null under one minute ('SS.T' clocks); readers refill it (creation.clock_seconds).
- **balldontlie (BDL)** (`bdl`): `GET https://api.balldontlie.io/v1|v2/... (key: BDL_KEY)`. player bios, draft year and pick, advanced per-period box (NBA.com ids). Terms: terms §6 permit republication while subscribed; subscription lapsed 2026-11-09, licensing decision pending with the owner. Stored: hoops_mart data/bdl, data/mart/bdl_*.parquet.
- **LUMA Basketball Research (CourtShare)** (`luma`): `luma MCP server (key: LUMA_KEY)`. xPTS-RAPM, Lens channels, on/off: validation reference only. Terms: never republished; credited wherever its numbers touched a gate. Stored: data/derived/*luma* caches (local).
